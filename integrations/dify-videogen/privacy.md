# VideoGen plugin privacy

This plugin sends your configured API key, selected resource identifiers and requested operation arguments to VideoGen's official hosted MCP service over HTTPS. VideoGen may process scripts, product descriptions, reference media and generated project data to carry out your request. Responses, including generated asset/project/download links, return to your Dify application and its configured model.

The plugin does not log keys, create its own analytics or persistent storage, read local user files, or download/export video bytes through the plugin runtime. Dify manages credential and application storage. VideoGen stores and processes service data under its [privacy policy](https://videogen.io/privacy-policy) and [terms](https://videogen.io/terms-of-service). Generation and exports can consume your account credits. Contact info@videogen.io for privacy requests.

Website: https://videogen.io/videogen-mcp
